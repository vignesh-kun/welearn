Local development runs via the Supabase CLI using `supabase/config.toml` (project_id `welearn`); migrations live in `supabase/migrations/` and are applied with `supabase db push` or `supabase db reset`. The Prisma client is generated from `prisma/schema.prisma` against a PostgreSQL instance whose connection string is supplied via the `DATABASE_URL` / `DIRECT_URL` environment variables.
