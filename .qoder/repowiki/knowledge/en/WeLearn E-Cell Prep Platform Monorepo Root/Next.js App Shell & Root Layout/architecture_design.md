Three files form the Next.js App Router root:
- `layout.tsx` is the server-side `RootLayout`: declares Next `Metadata`/`Viewport`, loads three Google Fonts (Space Grotesk, Plus Jakarta Sans, JetBrains Mono) as CSS variables (`--font-display`, `--font-body`, `--font-mono-nums`), injects an inline `THEME_BOOTSTRAP` script that reads `localStorage.welearn.theme.v2` and sets `document.documentElement.dataset.theme` plus the `.dark` class before paint to avoid a theme flash, then renders `<AmbientBackground />`, `{children}`, and `<Toaster />`.
- `page.tsx` is a client component (`"use client"`) that owns top-level auth state: on mount it calls `loadSession()` from `@/lib/session`, validates the session via `/api/auth/validate`, fetches streak stats via `@/lib/session.api`, and conditionally renders either `<AuthScreen>` or `<AppShell>` wrapping one of nine feature views (`home`, `puzzles`, `cases`, `gd`, `arena`, `quiz`, `crosswords`, `leaderboard`, `studio`).
- `globals.css` is the single source of truth for theming: Tailwind + tw-animate-css imports, a `@theme inline` block mapping semantic tokens to CSS variables, ten VS Code–style palettes exposed via `[data-theme="..."]` selectors (default `dark-plus`, plus `light-plus`, `pink-moon`, `yellow-nitro`, `dracula`, `monokai-pro`, `one-dark`, `abyss`, `synthwave-84`, `everglades`), base typography layer, and reusable animation/utility classes (`.aurora-bg`, `.glass-card`, `.tile-logo`, `.shimmer`, `.flip-card`, `.reels-scroll`, reduced-motion overrides).

Dependency direction is one-way outward: this module depends on `@/components/welearn/*` (AppShell, AuthScreen, AmbientBackground, Toaster) and `@/lib/session`; nothing in those packages depends back into the app shell.
