E2E smoke tests require a running server at `http://localhost:3000` before execution (`arena-smoke.mjs`, `e2e-restructure.mjs`). The SQLite→Supabase migration expects `prisma/db/custom.db` to exist and optionally a live Prisma connection to Supabase; if the network connection fails it falls back to writing `supabase/migrations/20261107_data_seed.sql` for manual execution. Shell tests create their own temp roots and are self-contained — no project state is modified outside `$TEST_ROOT`.
