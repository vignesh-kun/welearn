- All source imports use the `@/` path alias mapped to `./src/*` rather than relative paths.
- UI primitives come from shadcn/ui under `@/components/ui` and are styled via Tailwind CSS variables defined in `src/app/globals.css`.
- Database access goes through the Prisma-generated client (generated by `prisma generate` on postinstall) rather than raw SQL from the app shell.
