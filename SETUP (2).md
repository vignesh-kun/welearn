# WeLearn — Cursor Setup Guide

E-Cell WeLearn prep platform (built for the December E-Summit).
Stack: **Next.js 16 · TypeScript · Tailwind 4 · shadcn/ui · Prisma + SQLite · Groq AI · Framer Motion · Recharts**

---

## 1. Open in Cursor

1. Unzip `welearn.zip` anywhere, e.g. `~/projects/welearn`.
2. In Cursor: **File → Open Folder →** select the unzipped `welearn` folder.
3. Cursor's terminal: install dependencies (one of):

```bash
bun install        # fastest, matches bun.lock
# or
npm install
# or
pnpm install
```

## 2. Environment

`.env` is already in the zip:

```
DATABASE_URL=file:/home/z/my-project/db/custom.db
```

> After unzipping, change the absolute path to your new location, e.g.
> `DATABASE_URL=file:./db/custom.db` (relative paths work with Prisma).

If you want Groq AI (founder quiz, case studies, AI founder scenarios), add a key:

```
GROQ_API_KEY=gsk_...
```

Without a key, the app falls back to a curated local question bank — it still runs.

## 3. Database

```bash
bunx prisma generate      # generate the Prisma client
bunx prisma db push       # create tables from schema.prisma
bunx tsx scripts/seed.ts  # seed cases / terms / puzzles / quiz
```

The included `db/custom.db` already contains seed data, so `db push` is optional — only run it if you change `prisma/schema.prisma`.

## 4. Run dev server

```bash
bun run dev      # http://localhost:3000
# or
npm run dev
```

## 7. Features already implemented

- **Daily Puzzles** — server-scored, anti-cheat
- **Case Study Hub** — Zerodha / boAt / Lenskart real cases with YouTube embeds
- **GD & Debate** — original tab (kept as-is)
- **Arena** — unified GD / Debate / Pitching arena with optional timer, star ratings, host-end gating, delete-anywhere, Remarks tab
- **Terms & News** flip-cards — three-segment E-Cell definition + real founder story + warning
- **Founder Quiz** — 5 tracks (Investment / Growth / Ops & Legal / Product & Tech / Strategy), 4 question types (scenario / red_flag / micro_math / pitch_pairing), 8 auto-badges, 60-second elevator pitch pairing, Groq dynamic generation with fallback
- **Leaderboard** — across all modules
- **My Studio** — personal progress / badge wall
- **PIN 1408** — 2-step verify gate for any add/delete action (no admin page dependency)

## 8. Cursor tips

- Recommended Cursor setting: **Settings → enable `typescript.tsdk` per-workspace** so TS uses the project's version.
- For AI assistance, the existing `src/lib/ai.ts` already wires Groq with a model fallback chain (`llama-3.3-70b-versatile` → `openai/gpt-oss-120b` → `llama-3.1-8b-instant`). Cursor's chat doesn't read Groq — it just edits the code; the runtime model calls happen at dev time.
- `@dnd-kit`, `framer-motion`, `recharts`, `lucide-react`, `@radix-ui/*` are all preinstalled — no need to add UI libraries.

## 9. Things excluded from the zip

- `node_modules/` — run `bun install` / `npm install` to regenerate
- `.next/` — build output, regenerated by `next dev` / `next build`
- `.git/` — version history
- `skills/`, `tool-results/`, `examples/` — agent tooling, not project code
